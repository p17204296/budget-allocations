# Saving while you scroll

Editing a form shows a floating save prompt that stays available as you scroll. On phones and tablets it sits above the bottom navigation; on desktop it sits in the bottom-right corner. Extra page space lets you scroll the final controls clear of the prompt.

The prompt names the form you are saving and uses its normal action: Save changes, Add item, Update email, or Save currency, for example. It appears after an edit, rather than just opening a form. Cancelling or reverting the edit removes it.

If several forms have unsaved edits, the prompt follows the most recently edited form and shows how many other forms still have changes. Saving that form reveals the next pending form. It never submits unrelated forms together.

Events and monthly what-if retain their six-second autosave. **Save now** saves immediately; the prompt disappears once changes are saved. Invalid drafts offer **Check fields**, which takes you to a field needing attention. Failed saves offer **Retry save**, and conflicts offer **Review changes** using the existing confirmation flow.

Expenses, savings goals, income, accounts, assets, debts, and settings keep their existing manual submission behaviour. The floating action submits the same form as its inline button, including native validation. Inline actions remain available.

Feedback and sign-in dialogs retain their own actions. Read-only views and immediate actions have no pending draft to save.
